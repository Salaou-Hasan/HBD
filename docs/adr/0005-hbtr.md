# ADR 0005 — HBD Temporal Resolve replaces the disabled TAA

- **Status:** Accepted
- **Date:** 2026-11-20
- **Supersedes:** ADR 0003 (TAA disabled)
- **Related:** [ANTI-ALIASING.md](../ANTI-ALIASING.md)

## Context

The original TAA produced shake/ghosting and was disabled in ADR 0003. Separately, SSAO speckle remained because no temporal accumulation smoothed it. Adding only a spatial SSAO blur reduced noise but did not anti-alias geometry. The user asked for an original, high-quality, optimized AA rather than disabling AA.

Public sources (Karis, Salvi, UE/Unity/Godot documentation and the 2024 k-DOP paper) agree on jitter → reproject → validate history → blend. YCoCg variance clipping is the best cost/quality point; k-DOP is more robust but ~40% more expensive.

## Decision

Implement HBD Temporal Resolve (HBTR) and make it the default AA path (`HBTR_ENABLED = true`):

- 3×3 YCoCg mean/variance, segment clipping to `mean ± σ ∩ neighborhood`,
- confidence blend from reprojection distance and clip amount (no velocity target),
- luminance-adaptive weights, free sharpening from the same neighborhood,
- per-image history poses and ping-pong slots (retained from the corrected TAA bookkeeping).

The spatial SSAO bilateral blur is retained: HBTR smooths what moves through time, the half-res denoise removes stochastic AO noise before it enters the temporal accumulator.

## Consequences

- One extra full-res pass (~0.89 ms on Intel at 720p). Measured and documented, not hidden.
- Camera and objects must still be jittered by the same matrix used for reprojection; the per-image previous matrices are mandatory.
- Moving objects are handled by a velocity attachment (object motion only, camera motion stays with depth reprojection) plus per-image history age; the confidence blend remains the fallback when velocity is unavailable.
- ADR 0003's "re-enable criteria" are now met by a different implementation, so it is superseded rather than reversed.

## Verification

Static and orbit captures at 1280×720 showed clean edges, no grain, and no ghosting; the E2E profiler recorded the per-pass cost. See [ANTI-ALIASING.md](../ANTI-ALIASING.md) for numbers and [PROFILING.md](PROFILING.md) for methodology.
